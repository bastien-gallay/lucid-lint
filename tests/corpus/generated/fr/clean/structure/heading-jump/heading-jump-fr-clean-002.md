# Prendre le bus

Ce guide explique comment prendre le bus dans votre ville.

## Acheter un ticket

Vous pouvez acheter un ticket au guichet ou dans le bus.

## Monter dans le bus

Attendez à l'arrêt. Faites un signe au conducteur quand le bus arrive.

### Valider son ticket

Mettez le ticket dans la machine jaune. La machine fait un bip.
