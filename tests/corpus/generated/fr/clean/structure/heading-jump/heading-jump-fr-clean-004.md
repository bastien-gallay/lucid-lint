# Le jardin partagé du quartier

Le jardin partagé est ouvert à tous les habitants.

## S'inscrire

L'inscription est gratuite. Venez le samedi matin avec une pièce d'identité.

## Les règles du jardin

Chacun arrose ses plantes. On range les outils après usage.

### Les outils prêtés

Le jardin prête des pelles, des râteaux et des arrosoirs.

#### Où les ranger

Les outils vont dans le cabanon vert, près de l'entrée.
