Chaque mois, je vérifie mon budget en comptant mes dépenses dans un tableau. Je note les dépenses du mois, je compte l'argent qui reste, et je regarde les chiffres du tableau pour vérifier le budget. Il faut payer les factures, payer les courses, et noter chaque dépense dans le tableau pour que les chiffres du budget restent justes. Quand les dépenses du mois dépassent le budget, je regarde le tableau, je compte encore les chiffres, et je cherche où économiser de l'argent. Économiser sur les courses, économiser sur les factures : chaque mois, je veux économiser un peu d'argent pour que le budget du mois suivant respire. Je note, je compte, je vérifie : les factures à payer, les courses à payer, les dépenses à noter, les chiffres à vérifier dans le tableau. Mon budget est un tableau de chiffres, et chaque mois, le même travail recommence : compter l'argent, noter les dépenses, payer les factures, vérifier le tableau. Quand les chiffres sont bons, le budget du mois est bon, et l'argent économisé reste dans le tableau. Compter, noter, payer, vérifier, économiser : voilà mon budget, mois après mois, dépense après dépense, chiffre après chiffre.
